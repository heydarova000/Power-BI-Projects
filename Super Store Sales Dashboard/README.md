# Super Store Sales & Forecast Analysis

## Project Overview
This project focuses on analyzing Super Store sales performance and generating a 15-day sales forecast using Microsoft Power BI.

The dashboard provides interactive insights into sales, profit, customer segments, regional performance, shipping methods, and product categories. It also includes a sales forecasting analysis to identify future sales trends.

## Dashboard Preview

### 1. Super Store Sales Dashboard
This dashboard provides an overview of business performance and helps identify key sales and profitability trends.

**Key Features:**
- Total Sales, Profit, Order Count and Average Shipping Days KPIs
- Sales Analysis by Region
- Sales Analysis by Customer Segment
- Monthly Sales and Profit Trends
- Sales by Shipping Mode
- Sales by Product Category and Sub-Category
- Geographic Sales Distribution by State
- Interactive Regional Filters

### 2. 15-Day Sales Forecast
This dashboard focuses on predicting future sales trends based on historical sales data.

**Key Features:**
- 15-Day Sales Forecast
- Forecast Trend Visualization
- Interactive Forecast with Zoom Functionality
- Sales Distribution by State
- Identification of High-Performing States

## Tools & Technologies
- Microsoft Power BI
- DAX
- Power Query
- Data Visualization
- Sales Forecasting

## Key Insights
- California generates the highest sales among the displayed states.
- Standard Class is the leading shipping method by sales.
- The Technology category is one of the major sales contributors.
- Regional and monthly sales trends provide insights into business performance.
- The forecasting dashboard helps explore expected sales patterns over the next 15 days.

## Project Objective
The main objective of this project is to transform raw sales data into meaningful business insights through interactive dashboards and forecasting analysis.
