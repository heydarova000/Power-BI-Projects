# Sales Performance Report

## Project Overview

This project is an interactive Sales Performance Dashboard developed using Microsoft Power BI. It provides insights into sales performance, profitability, product performance, regional sales, and promotional activities.

The dashboard helps analyze business performance through interactive visualizations, key performance indicators (KPIs), and dynamic filters.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Dashboard Pages

### 1. Initial Analysis

Provides an overview of overall sales performance and business metrics.

**Key Performance Indicators (KPIs):**
- Total Sales
- Total Profit
- Total Quantity
- Order Count
- Sales Growth %
- Profit Growth %

**Visualizations:**
- Monthly Sales Trend
- Weekly Sales Analysis
- Top 10 Products by Sales
- Sales by Brand
- Sales by Product Category

### 2. Regional Analysis

Focuses on geographical sales performance and promotional analysis.

**Visualizations:**
- Total Sales by State
- Sales by Promotion Name
- Sales by Channel
- Profit by Channel
- Geographical Sales Distribution

## Key Features

- Interactive dashboard navigation
- Regional filtering by state
- Discount analysis (No Discount / Seasonal Discount)
- Dynamic KPI calculations
- Product and brand performance analysis
- Sales and profitability comparisons
- Interactive data visualizations

## Project Objectives

- Monitor overall sales performance.
- Identify top-performing products and brands.
- Analyze regional sales distribution.
- Evaluate the impact of promotional campaigns.
- Compare sales and profit across different channels.
- Support data-driven business decisions.
