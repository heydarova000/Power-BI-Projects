# Financial Analysis Dashboard

## Project Overview
This project presents a comprehensive financial analysis dashboard developed using Microsoft Power BI.

The dashboard provides insights into financial performance, revenue, expenses, profitability, cash flow, and balance sheet metrics.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Dashboard Pages

### 1. Executive Summary
- Total Revenue
- Total Expenses
- Gross Profit
- Net Profit
- Gross Margin %
- Gross Margin Trend
- Actual vs Budget Analysis
- Revenue vs Net Profit Trend

### 2. Variance Analysis
Financial performance and budget variance analysis.

### 3. Cash Flow Analysis
Analysis of cash inflows, outflows, and net cash flow.

### 4. Balance Sheet Analysis
Analysis of assets, liabilities, and financial position.

## Project Objectives
- Analyze financial performance.
- Monitor profitability.
- Compare actual results with budget.
- Evaluate cash flow.
- Support data-driven decision-making.
